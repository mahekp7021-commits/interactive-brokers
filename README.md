# Global Markets Demo — Multi-page static website

Independent educational UI prototype inspired by common global brokerage website patterns. Not affiliated with Interactive Brokers.

## Pages
Home, Why Platform, Pricing, Markets, Platforms, Services, Education, Account Types, Support, About, Research and Disclosures.

## Local run
Open `index.html` in any browser. All pages are static and share `assets/site.css` and `assets/site.js`.

## GitHub Pages
In repository Settings → Pages, choose **GitHub Actions** as the source. The workflow in `.github/workflows/pages.yml` publishes the root site on pushes to `main`.

## Safety
Non-functional educational demo. No login, trading, payments or personal-data submission. Any sample values are illustrative. Not affiliated with Interactive Brokers and not financial advice.
